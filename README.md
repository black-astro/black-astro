### 안녕하세요, 백엔드 개발자 **김현우** 입니다 <img src="https://media.giphy.com/media/hvRJCLFzcasrR4ia7z/giphy.gif" width="26">

통신·메시징 도메인에서 **KT 명세서 대용량 배치, 카카오 알림톡, PASS 본인인증** 같은
"많이, 안 끊기게 보내는" 서버들을 설계하고 굴려온 지 5년쯤 됐습니다.

- 🧵 1GB짜리 XML을 **메모리에 다 안 올리고** StAX로 흘려보내다가, Java 21 Virtual Thread 만나고 신났습니다.
- 🔐 하나의 백엔드에서 클라이언트 3종을 `SecurityFilterChain` 세 개로 나눠 인증하는 식의, **경계를 코드로 그리는 설계**를 좋아합니다.
- 🐛 운영 사고는 로그보다 **SQL로 먼저 재현**하고, 고친 뒤엔 꼭 README에 남겨 재발을 0으로 만드는 편입니다.
- 📦 프레임워크를 쓰기만 하는 게 아쉬워서, 직접 스타터 라이브러리를 만들어 **Maven Central에 올려봤습니다.**
- ☕ 요즘은 커피 한 잔 놓고 레거시를 Netty로 현대화하는 사이드 프로젝트를 만지작거리고 있어요.

## 📌 만든 것들

> 회사 서비스는 도메인만 간단히, 공개해도 되는 건 링크까지 붙였습니다.

### 🟢 [`easy-quartz`](https://github.com/black-astro/easy-quartz) &nbsp;·&nbsp; Maven Central 배포 OSS

어노테이션 하나(`@EasyQuartzScheduled`)로 **5종 스케줄 × 2엔진(Quartz/Spring)**을 통합한 Spring Boot Starter.
Auto-Configuration·AOP 프록시·Bean Lifecycle을 "쓰는 입장"이 아니라 "만드는 입장"에서 다뤄본 프로젝트입니다.
태그 push 한 번으로 GPG 서명 → Sonatype Central까지 무인 배포되도록 릴리즈를 자동화했습니다.

```gradle
implementation "io.github.black-astro:easy-quartz-spring-boot-starter:0.1.0"
```

### 🔵 [`shadowport`](https://github.com/black-astro/shadowport) &nbsp;·&nbsp; 레거시 리버스 터널 현대화

오래된 리버스 커넥션 도구를 **Java 21 · Netty · AES-GCM/X25519 · JavaFX**로 다시 쓰고 있는 사이드 프로젝트.
네트워크·보안 도메인을 공부하면서 GUI/패키징/빌드까지 직접 현대화하는 중입니다.

### ⚙️ 회사에서 (도메인만)

- **대용량 명세서 배치** — StAX 스트리밍 + MyBatis `BATCH` + Virtual Thread로 OOM 없이 대량 ETL
- **알림톡 발송 서버** — 외부 API를 트랜잭션 밖으로 뺀 상태머신 설계, 스케줄러 race를 DB 원자성으로 차단
- **본인인증(PASS) 발송** — N-스레드 stagger 분산 + Jenkins/SonarQube 품질 게이트 자동화
- **통합 인증 백엔드** — 단일 서버에서 멀티 `SecurityFilterChain` + 멀티 DataSource 운영
