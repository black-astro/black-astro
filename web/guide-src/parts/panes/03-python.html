쉽게 말하면 — f"{값:형식}"에서 콜론 뒤는 “어떻게 보여줄지”만 정합니다. 값 자체는 바뀌지 않습니다. >10=오른쪽 정렬 10칸, .2f=소수점 2자리, ,=천 단위 콤마. 이 셋이면 90%는 해결됩니다.

f-string 중괄호 안에서 콜론(:) 뒤에 오는 부분은 사실 별도의 작은 언어입니다. 순서는 [채움문자][정렬][부호][#][0][너비][,_][.정밀도][타입]. 이거 하나면 로그·보고서·표 출력이 전부 해결됩니다.

고급 — 정규식은 이 정도만 알면 대부분 해결됩니다

쉽게 말하면 — 정규식은 “글자 모양을 설명하는 규칙”입니다. \d=숫자 하나, +=1개 이상, ( )=여기를 꺼내줘. 이 셋만 알아도 로그에서 숫자·날짜 뽑기는 됩니다. 복잡해지면 regex101.com에 붙여 넣으면 한 조각씩 뜻을 설명해 줍니다.

re 5총사

import re

log = "2026-07-31 14:05 ERROR 결제 실패 code=402"

re.search(r"code=(\d+)", log).group(1)   # '402'  어디에 있든 찾기
re.match(r"\d{4}", log)                  # 문자열 '맨 앞'만 검사
re.findall(r"[A-Z]{3,}", log)            # ['ERROR']  전부 찾기
re.sub(r"\d{4}-\d{2}-\d{2}", "[날짜]", log)   # 치환
re.split(r"\s+", log)                    # 공백(여러 칸)으로 분리

# 이름 붙은 그룹 — 가독성이 완전히 달라집니다
m = re.match(r"(?P<date>\S+) (?P<time>\S+) (?P<level>\w+)", log)
m.group("level")     # 'ERROR'
m.groupdict()        # {'date': '2026-07-31', 'time': '14:05', …}

# 자주 쓰면 미리 컴파일해 두기
DATE = re.compile(r"^\d{4}-\d{2}-\d{2}$")
bool(DATE.match("2026-07-31"))     # True

쉽게 말하면 — 문자열은 “글자들이 줄 서 있는 것”입니다. 자르고(split) · 붙이고(join) · 바꾸고(replace) · 모양 다듬기(f"{값:형식}") 이 네 가지가 전부입니다. 그리고 바꾼 결과는 반드시 다시 변수에 담아야 합니다.

def handle(event):
    match event:
        # dict 모양 + 안쪽 값을 x, y 로 바로 꺼냄
        case {"type": "click", "x": x, "y": y}:
            return f"클릭 ({x}, {y})"

        # 조건(guard) 을 덧붙일 수 있습니다
        case {"type": "key", "code": code} if code < 32:
            return "제어 문자"

        # 리스트 모양 — 나머지는 *rest 로
        case ["move", *rest]:
            return f"이동 {rest}"

        # 클래스 모양 (dataclass·NamedTuple 과 궁합이 좋습니다)
        case Point(x=0, y=0):
            return "원점"

        # 타입 검사 + 이름 붙이기
        case str() as s:
            return s.upper()

        case 1 | 2 | 3:          # 여러 값 중 하나
            return "작은 수"

        case _:                  # 나머지 전부 (default)
            return "모름"

        return iter(self.상품들)

✅ 클래스가 맞는 상황

  • 상태 + 동작이 함께 다닐 때 — 커넥션, 게임 캐릭터, 진행 중인 작업
  • 같은 데이터 묶음이 코드 곳곳을 돌아다닐 때 → @dataclass
  • 같은 인터페이스, 다른 구현이 여럿일 때 — 저장소를 파일/DB/메모리로 갈아끼우기
  • 객체가 수명 주기를 가질 때 — 열고 · 쓰고 · 닫고(with)

⚠️ 함수면 충분한 상황

  • 메서드가 하나뿐인 클래스 → 그냥 함수로
  • __init__에서 받은 걸 그대로 쓰기만 하는 클래스 → 함수 인자로
  • Java 습관으로 만든 XxxUtil·XxxManager → 파이썬은 모듈(파일)이 곧 네임스페이스라 클래스로 감쌀 필요가 없습니다
  • 값만 담는 묶음 → @dataclass나 dict·NamedTuple로 충분
Spring 개발자에게 — @Service 하나에 메서드 하나인 클래스를 파이썬에서 그대로 옮기면 대개 파일 하나에 함수 몇 개가 더 읽기 좋습니다. 의존성 주입도 “생성자에 넣기” 대신 함수 인자로 넘기는 편이 자연스럽습니다.

import functools, time

def timer(func):
    @functools.wraps(func)          # 원본 이름/독스트링 보존
    def wrapper(*args, **kwargs):
        t = time.perf_counter()
        result = func(*args, **kwargs)
        print(f"{func.__name__}: {time.perf_counter()-t:.3f}s")
        return result
    return wrapper

@timer                              # 이 한 줄이 핵심
def slow_task():
    time.sleep(1)

slow_task()      # slow_task: 1.001s

# 자주 쓰는 내장 데코레이터
from functools import lru_cache

@lru_cache(maxsize=128)             # 결과 캐싱
def fib(n):
    return n if n < 2 else fib(n-1) + fib(n-2)

    t = time.perf_counter()
    try:
        yield                      # 여기서 with 블록 실행
    finally:
        print(f"{label}: {time.perf_counter()-t:.3f}s")

with 시간측정("집계"):
    df.groupby("팀").sum()

@contextmanager
def transaction(path):
    conn = sqlite3.connect(path)
    try:
        yield conn
        conn.commit()              # 정상 종료 → 커밋
    except Exception:
        conn.rollback()            # 예외 → 롤백

Spring 비유 — @Transactional의 수동 구현입니다. yield 앞 = 진입(before), yield 뒤 = 종료(after/finally). 자원 획득·해제 쌍이 있는 모든 곳(락, 임시 디렉터리, DB)에 씁니다.

from typing import Protocol, TypeVar, overload

# Protocol = 구조적 인터페이스 (implements 선언 불필요!)
class Exportable(Protocol):
    def to_excel(self, path: str) -> None: ...

def 저장(report: Exportable, path: str):
    report.to_excel(path)      # to_excel 만 있으면 어떤 객체든 OK

def first[T](items: list[T]) -> T | None:
    return items[0] if items else None

# 구버전 문법
T = TypeVar("T")
def first(items: list[T]) -> T | None: ...

# overload — 인자에 따라 반환 타입이 다를 때
@overload
def load(path: str, as_df: bool = True) -> "pd.DataFrame": ...
@overload
def load(path: str, as_df: bool = False) -> dict: ...
Protocol이 Java 인터페이스보다 나은 점 — 대상 클래스가 내 인터페이스를 몰라도 됩니다(덕 타이핑의 정적 검증). 외부 라이브러리 객체도 시그니처만 맞으면 통과합니다. 검증은 uv run mypy . 또는 IDE가 합니다.
정리 — yield는 return의 “일시정지” 버전입니다. 값을 하나 주고 그 자리에서 멈췄다가, 다음에 부르면 그 자리부터 이어서 계속합니다. 그래서 1억 건도 메모리 없이 흘려보낼 수 있습니다. 데코레이터 @는 “원래 함수를 건드리지 않고 겉을 감싸는 것” — 로그·시간 측정·캐시를 붙일 때 씁니다.
