Rust 백엔드는 언제 이기나 — 그리고 언제 지나

“빠르다”는 말만으로는 팀을 설득할 수 없습니다. 실제로 돈이 되는 지점은 같은 트래픽을 받는 데 인스턴스가 몇 대 필요한가, 그리고 p99 지연이 GC 때문에 튀지 않는가 두 가지입니다. 이 절은 그 두 가지를 숫자와 사례로 확인하고, 프레임워크를 고르는 기준까지 정리합니다.

WEB 02

Axum 구조 완전 이해 — Router · Extractor · Layer 가 맞물리는 방식

실전 탭(🧰 t05)에서 “요청이 네 단계를 지난다”고만 봤습니다. 여기서는 그 네 단계가 각각 어떤 트레이트로 구현돼 있는지를 봅니다. 이걸 알면 “the trait Handler is not implemented” 같은 난해한 에러가 전부 읽히기 시작합니다 — Axum 을 쓰다 막히는 지점의 90%가 여기입니다.

본문을 소비하는 추출기는 맨 마지막 인자 하나뿐 — 이 규칙 하나가 Axum 에러의 절반입니다.

tower 의 Service · Layer 는 이게 전부입니다

// tower::Service — "요청을 받아 미래의 응답을 준다"
pub trait Service<Request> {
    type Response;
    type Error;
    type Future: Future<Output = Result<Self::Response, Self::Error>>;

    // 받을 준비가 됐는지 — 백프레셔가 여기서 나옵니다 ★
    fn poll_ready(&mut self, cx: &mut Context<'_>)
        -> Poll<Result<(), Self::Error>>;

    fn call(&mut self, req: Request) -> Self::Future;
}

// tower::Layer — "서비스를 감싸 새 서비스를 만든다"
pub trait Layer<S> {
    type Service;
    fn layer(&self, inner: S) -> Self::Service;
}

// ★ Router 도 Service, 핸들러도 결국 Service, 미들웨어도 Service 입니다.
//   전부 같은 타입으로 조립되기 때문에 순서를 마음대로 바꿔 낄 수 있습니다.
스프링과 비교하면 — Filter 체인과 같은 역할이지만, 런타임 리플렉션이 아니라 제네릭 중첩으로 만들어집니다. 그래서 실행 비용이 사실상 0이고(인라인됨), 대신 타입 이름이 무섭게 길어집니다 — Router 로 지우면 됩니다.

Router — merge · nest · fallback 세 가지

use axum::{Router, routing::{get, post, put, delete}};

fn user_routes() -> Router<AppState> {
    Router::new()
        .route("/", get(list).post(create))       // 같은 경로 다른 메서드
        .route("/{id}", get(detail).put(update).delete(remove))
}

let api = Router::new()
    .nest("/users",  user_routes())               // 경로 앞에 접두사를 붙임
    .nest("/orders", order_routes())
    .merge(health_routes());                      // 같은 층에 합침

let app = Router::new()
    .nest("/api/v1", api)
    .fallback(handler_404)                        // 매칭 실패
    .method_not_allowed_fallback(handler_405)     // 경로는 맞고 메서드가 틀림
    .with_state(state);                           // ★ 반드시 마지막

// Axum 0.8 에서 바뀐 것 ★
//   경로 변수 표기가 :id → {id} 로 바뀌었습니다 (0.7 코드는 여기서 깨집니다)
//   와일드카드는 *rest → {*rest}
.route("/files/{*path}", get(serve_file))
.with_state() 는 맨 마지막에 부릅니다. 그 전까지 Router<AppState> 였다가 Router<()> 가 되고, axum::serve 는 Router<()> 만 받습니다. “상태를 붙였는데 타입이 안 맞는다”는 에러의 대부분이 순서 문제입니다.

FromRequestParts — 본문을 안 건드리는 추출기

use axum::{extract::FromRequestParts, http::request::Parts};

/// 헤더에서 요청 ID 를 꺼내거나 없으면 새로 만듭니다
pub struct ReqId(pub String);

impl<S: Send + Sync> FromRequestParts<S> for ReqId {
    type Rejection = std::convert::Infallible;    // 실패할 수 없음

    async fn from_request_parts(parts: &mut Parts, _s: &S)
        -> Result<Self, Self::Rejection>
    {
        let id = parts.headers
            .get("x-request-id")
            .and_then(|v| v.to_str().ok())
            .map(str::to_owned)
            .unwrap_or_else(|| uuid::Uuid::now_v7().to_string());
        Ok(ReqId(id))
    }
}

// 쓰는 쪽 — 인자 하나 추가하면 끝입니다
async fn handler(ReqId(rid): ReqId) -> String {
    format!("req={rid}")
}
Axum 0.8 부터는 #[async_trait] 가 필요 없습니다 — 트레이트에 async fn 을 그대로 씁니다(Rust 1.75+ 의 AFIT). 인터넷의 0.6·0.7 예제를 그대로 붙이면 async_trait 관련 에러가 나는 이유입니다.

검증까지 하는 Json 래퍼 — 실무에서 가장 많이 만듭니다

use axum::extract::{FromRequest, Request, rejection::JsonRejection};

/// axum::Json 을 감싸 "파싱 + validator 검증"을 한 번에
pub struct Valid<T>(pub T);

impl<S, T> FromRequest<S> for Valid<T>
where
    S: Send + Sync,
    T: serde::de::DeserializeOwned + validator::Validate,
    axum::Json<T>: FromRequest<S, Rejection = JsonRejection>,
{
    type Rejection = AppError;                    // 우리 공통 에러 (w03)

    async fn from_request(req: Request, state: &S) -> Result<Self, Self::Rejection> {
        let axum::Json(v) = axum::Json::<T>::from_request(req, state).await?;
        v.validate()?;                            // 실패하면 422 로 나갑니다
        Ok(Valid(v))
    }
}

// 핸들러가 이렇게 짧아집니다 — 검증 코드가 사라집니다 ★
async fn create_user(
    State(st): State<AppState>,
    Valid(body): Valid<CreateUser>,               // ← 반드시 마지막 인자
) -> Result<Json<User>, AppError> {
    Ok(Json(service::create(&st, body).await?))
}

// crates/api/src/error.rs
use axum::{http::StatusCode, response::{IntoResponse, Response}, Json};
use serde::Serialize;

#[derive(thiserror::Error, Debug)]
pub enum AppError {
    #[error("{0}")]                    Validation(String),
    #[error("인증이 필요합니다")]        Unauthorized,
    #[error("권한이 없습니다")]          Forbidden,
    #[error("{0} 을(를) 찾을 수 없습니다")] NotFound(&'static str),
    #[error("이미 존재합니다")]          Conflict,
    #[error("요청이 너무 많습니다")]      TooManyRequests,
    // ↓ 내부 오류 — 사용자에게 내용을 보여 주지 않습니다 ★
    #[error(transparent)]              Db(#[from] sqlx::Error),
    #[error(transparent)]              Other(#[from] anyhow::Error),
}

#[derive(Serialize)]
struct ErrBody<'a> {
    code: &'a str,          // 기계용 — 클라이언트가 분기하는 값
    message: String,        // 사람용
    #[serde(skip_serializing_if = "Option::is_none")]
    trace_id: Option<String>,
}

impl IntoResponse for AppError {
    fn into_response(self) -> Response {
        // sqlx 의 "행 없음"은 404 로 자동 변환 ★ 핸들러가 깨끗해집니다
        let (status, code) = match &self {
            AppError::Validation(_)    => (StatusCode::UNPROCESSABLE_ENTITY, "VALIDATION"),
            AppError::Unauthorized     => (StatusCode::UNAUTHORIZED, "UNAUTHORIZED"),
            AppError::Forbidden        => (StatusCode::FORBIDDEN, "FORBIDDEN"),
            AppError::NotFound(_)      => (StatusCode::NOT_FOUND, "NOT_FOUND"),
            AppError::Conflict         => (StatusCode::CONFLICT, "CONFLICT"),
            AppError::TooManyRequests  => (StatusCode::TOO_MANY_REQUESTS, "RATE_LIMITED"),
            AppError::Db(sqlx::Error::RowNotFound) => (StatusCode::NOT_FOUND, "NOT_FOUND"),
            _                          => (StatusCode::INTERNAL_SERVER_ERROR, "INTERNAL"),
        };

        let message = if status == StatusCode::INTERNAL_SERVER_ERROR {
            // 내부 세부 정보는 로그로만 남깁니다 — 응답에 스택을 흘리지 마세요 ★
            tracing::error!(error = ?self, "요청 처리 실패");
            "서버 오류가 발생했습니다".to_string()
        } else {
            self.to_string()
        };

        let trace_id = tracing::Span::current()
            .field("trace_id").map(|_| current_trace_id());   // w10

        (status, Json(ErrBody { code, message, trace_id })).into_response()
    }
}

pub async fn transfer(pool: &PgPool, from: Uuid, to: Uuid, amt: i64)
    -> Result<(), AppError>
{
    let mut tx: Transaction<'_, Postgres> = pool.begin().await?;

    // 잔액 확인은 반드시 잠금과 함께 ★ 안 하면 이중 출금이 납니다
    let bal: i64 = sqlx::query_scalar!(
        "SELECT balance FROM accounts WHERE id = $1 FOR UPDATE", from)
        .fetch_one(&mut *tx).await?;
    if bal < amt { return Err(AppError::Validation("잔액 부족".into())); }
    //             ↑ 여기서 반환하면 tx 가 Drop 되며 자동 롤백됩니다

    sqlx::query!("UPDATE accounts SET balance = balance - $1 WHERE id = $2", amt, from)
        .execute(&mut *tx).await?;
    sqlx::query!("UPDATE accounts SET balance = balance + $1 WHERE id = $2", amt, to)
        .execute(&mut *tx).await?;

    tx.commit().await?;          // ★ 이걸 빠뜨리면 조용히 롤백
    Ok(())
}

use tower::ServiceBuilder;
use tower_http::{
    catch_panic::CatchPanicLayer,
    request_id::{MakeRequestUuid, SetRequestIdLayer, PropagateRequestIdLayer},
    trace::{TraceLayer, DefaultMakeSpan, DefaultOnResponse},
    cors::{CorsLayer, AllowOrigin},
    compression::CompressionLayer,
    timeout::TimeoutLayer,
    sensitive_headers::SetSensitiveRequestHeadersLayer,
};
use axum::http::{header, Method};

pub fn router(state: AppState) -> Router {
    let cors = CorsLayer::new()
        .allow_origin(AllowOrigin::list([
            "https://app.example.com".parse().unwrap(),
        ]))                                       // ★ permissive 를 운영에 쓰지 마세요
        .allow_methods([Method::GET, Method::POST, Method::PUT, Method::DELETE])
        .allow_headers([header::AUTHORIZATION, header::CONTENT_TYPE])
        .allow_credentials(true)                  // 쿠키를 쓸 때만
        .max_age(Duration::from_secs(3600));      // 프리플라이트 캐시

    // ★ ServiceBuilder 는 "위에서 아래" 가 "바깥에서 안쪽" 입니다
    let middleware = ServiceBuilder::new()
        .layer(CatchPanicLayer::new())                       // ① 최후의 방어
        .layer(SetSensitiveRequestHeadersLayer::new([header::AUTHORIZATION]))
        .layer(SetRequestIdLayer::x_request_id(MakeRequestUuid))
        .layer(TraceLayer::new_for_http()                    // ② 여기서부터 로그
            .make_span_with(DefaultMakeSpan::new().include_headers(false))
            .on_response(DefaultOnResponse::new().level(tracing::Level::INFO)))
        .layer(PropagateRequestIdLayer::x_request_id())      // 응답에도 실어 보냄
        .layer(cors)                                         // ③ 프리플라이트는 여기서 끝
        .layer(CompressionLayer::new())                      // ④ 나가는 길에 압축
        .layer(TimeoutLayer::new(Duration::from_secs(15)));  // ⑤ 핸들러 상한

    Router::new()
        .nest("/api/v1", api_routes())
        .route("/health", get(health))          // ★ 헬스체크는 로그·인증 제외 라우터로
        .layer(middleware)
        .with_state(state)
}

use axum::{middleware::Next, extract::Request, response::Response};

/// 응답 시간을 재고 느린 요청에 경고를 남깁니다
async fn timing(req: Request, next: Next) -> Response {
    let path = req.uri().path().to_owned();
    let method = req.method().clone();
    let started = std::time::Instant::now();

    let mut res = next.run(req).await;      // ★ 안쪽 서비스 호출

    let ms = started.elapsed().as_millis() as u64;
    if ms > 500 {
        tracing::warn!(%method, %path, ms, "느린 요청");
    }
    res.headers_mut().insert(
        "x-response-time-ms",
        ms.to_string().parse().unwrap());
    res
}

정석 — Layer + Service 직접 구현

use std::task::{Context, Poll};
use tower::{Layer, Service};

#[derive(Clone)]
pub struct ConcurrencyGuard<S> {
    inner: S,
    sem: std::sync::Arc<tokio::sync::Semaphore>,
}

#[derive(Clone)]
pub struct ConcurrencyGuardLayer(pub std::sync::Arc<tokio::sync::Semaphore>);

impl<S> Layer<S> for ConcurrencyGuardLayer {
    type Service = ConcurrencyGuard<S>;
    fn layer(&self, inner: S) -> Self::Service {
        ConcurrencyGuard { inner, sem: self.0.clone() }
    }
}

impl<S, B> Service<Request<B>> for ConcurrencyGuard<S>
where
    S: Service<Request<B>, Response = Response> + Clone + Send + 'static,
    S::Future: Send + 'static,
    B: Send + 'static,
{
    type Response = S::Response;
    type Error = S::Error;
    type Future = std::pin::Pin<Box<dyn Future<Output =
        Result<Self::Response, Self::Error>> + Send>>;

    fn poll_ready(&mut self, cx: &mut Context<'_>) -> Poll<Result<(), Self::Error>> {
        self.inner.poll_ready(cx)
    }

    fn call(&mut self, req: Request<B>) -> Self::Future {
        // ★ Clone 트릭 — poll_ready 를 통과한 인스턴스를 써야 합니다
        let clone = self.inner.clone();
        let mut inner = std::mem::replace(&mut self.inner, clone);
        let sem = self.sem.clone();
        Box::pin(async move {
            let _permit = sem.acquire().await.unwrap();   // 동시 실행 수 제한
            inner.call(req).await
        })
    }
}
std::mem::replace 트릭을 반드시 기억하세요. tower 규약상 poll_ready 로 준비를 확인한 바로 그 인스턴스에 call 을 해야 합니다. self.inner.clone() 을 그대로 쓰면 준비되지 않은 복제본을 호출하는 셈이라 간헐적 패닉이 납니다.

인증에서 사고가 나는 자리는 알고리즘이 아니라 빠뜨림입니다 — 새 엔드포인트를 추가하면서 권한 검사를 안 넣는 것. Rust 에서는 “인증된 사용자”를 타입으로 만들어 핸들러 인자에 요구하면 검사를 빠뜨린 핸들러가 애초에 컴파일되지 않게 할 수 있습니다. 그 방법을 만듭니다.

use argon2::{Argon2, PasswordHasher, PasswordVerifier, PasswordHash,
             password_hash::{SaltString, rand_core::OsRng}};

pub fn hash_password(plain: &str) -> anyhow::Result<String> {
    let salt = SaltString::generate(&mut OsRng);      // 소금은 매번 새로
    let hash = Argon2::default()                      // Argon2id 기본 파라미터
        .hash_password(plain.as_bytes(), &salt)
        .map_err(|e| anyhow::anyhow!("{e}"))?
        .to_string();      // "$argon2id$v=19$m=19456,t=2,p=1$..." 형태 ★
    Ok(hash)               // 소금과 파라미터가 문자열 안에 함께 들어갑니다
}

pub fn verify_password(plain: &str, stored: &str) -> bool {
    PasswordHash::new(stored)
        .map(|p| Argon2::default().verify_password(plain.as_bytes(), &p).is_ok())
        .unwrap_or(false)
}

// ★ 반드시 spawn_blocking 으로 감싸세요
//   argon2 검증은 의도적으로 수십~수백 ms 가 걸리는 CPU 작업입니다.
//   그대로 두면 워커 스레드가 그동안 통째로 막힙니다 (🧰 t04)
let ok = tokio::task::spawn_blocking({
    let (p, h) = (plain.to_owned(), stored.to_owned());
    move || verify_password(&p, &h)
}).await?;

// ★ 사용자가 없을 때도 더미 해시로 검증을 수행하세요.
//   바로 반환하면 응답 시간 차이로 "그 이메일이 있는지" 가 새어 나갑니다.
메모리 파라미터를 낮추지 마세요. Argon2 의 방어력은 메모리 비용에서 나옵니다. 기본값(19MiB)이 부담되면 인스턴스를 늘리는 편이 낫지, m 을 4MiB 로 내리는 것은 공격자를 도와주는 일입니다.

JWT — 발급과 검증

use jsonwebtoken::{encode, decode, Header, Algorithm,
                   EncodingKey, DecodingKey, Validation};
use serde::{Serialize, Deserialize};

#[derive(Serialize, Deserialize)]
pub struct Claims {
    pub sub: String,        // 사용자 ID
    pub role: Role,         // 역할
    pub exp: i64,           // 만료 (필수 ★)
    pub iat: i64,           // 발급 시각
    pub iss: String,        // 발급자
    pub aud: String,        // 대상 — 다른 서비스 토큰이 넘어오는 걸 막습니다
    pub jti: String,        // 토큰 고유 ID (폐기 목록용)
}

pub struct JwtKeys { enc: EncodingKey, dec: DecodingKey, val: Validation }

impl JwtKeys {
    pub fn new(cfg: &AuthCfg) -> anyhow::Result<Self> {
        // HS256: 대칭키(간단) · RS256/EdDSA: 비대칭(공개키 배포 가능) ★
        let secret = cfg.jwt_secret.expose_secret().as_bytes();
        let mut val = Validation::new(Algorithm::HS256);
        val.set_issuer(&[cfg.issuer.as_str()]);
        val.set_audience(&[cfg.audience.as_str()]);
        val.leeway = 5;                       // 시계 오차 허용(초)
        Ok(Self {
            enc: EncodingKey::from_secret(secret),
            dec: DecodingKey::from_secret(secret),
            val,
        })
    }

    pub fn issue(&self, user: &User, ttl: Duration) -> anyhow::Result<String> {
        let now = chrono::Utc::now();
        let c = Claims {
            sub: user.id.to_string(), role: user.role,
            iat: now.timestamp(),
            exp: (now + ttl).timestamp(),
            iss: "myservice".into(), aud: "myservice-web".into(),
            jti: uuid::Uuid::now_v7().to_string(),
        };
        Ok(encode(&Header::new(Algorithm::HS256), &c, &self.enc)?)
    }

    pub fn verify(&self, token: &str) -> Result<Claims, AppError> {
        decode::<Claims>(token, &self.dec, &self.val)
            .map(|d| d.claims)
            .map_err(|_| AppError::Unauthorized)
    }
}
절대 하지 말 것 세 가지 — ① Validation 의 validate_exp 를 끄기, ② 알고리즘을 토큰의 alg 헤더에서 읽어 쓰기(alg: none 공격), ③ 토큰에 개인정보나 권한 원본 데이터 넣기 — JWT 는 암호화가 아니라 서명이라 누구나 내용을 읽을 수 있습니다.

            id: claims.sub.parse().map_err(|_| AppError::Unauthorized)?,
            role: claims.role,
        })
    }

pub async fn refresh(st: &AppState, raw: &str) -> ApiResult<TokenPair> {
    let hash = sha2::Sha256::digest(raw.as_bytes());
    let mut tx = st.db.begin().await?;

    let row = repo::find_refresh(&mut *tx, &hash).await?
        .ok_or(AppError::Unauthorized)?;

    if row.used_at.is_some() {
        // ★ 이미 쓰인 토큰이 또 왔다 = 누군가 훔쳤다는 강한 신호
        //   그 계보 전체를 무효화하고 사용자에게 알립니다
        repo::revoke_family(&mut *tx, row.family_id).await?;
        tx.commit().await?;
        tracing::warn!(user = %row.user_id, "리프레시 토큰 재사용 감지");
        return Err(AppError::Unauthorized);
    }
    if row.expires_at < Utc::now() { return Err(AppError::Unauthorized); }

    repo::mark_used(&mut *tx, row.id).await?;
    let pair = issue_pair(&mut *tx, st, row.user_id, row.family_id).await?;
    tx.commit().await?;
    Ok(pair)
}

            .interval(Duration::from_secs(15))    // ★ 프록시가 끊지 않게
            .text("ping"))

use axum::extract::ws::{WebSocket, WebSocketUpgrade, Message, Utf8Bytes};
use futures::{SinkExt, StreamExt};

async fn ws_handler(
    ws: WebSocketUpgrade,
    user: AuthUser,                       // ★ 업그레이드 전에 인증합니다
    Path(room): Path<String>,
    State(st): State<AppState>,
) -> impl IntoResponse {
    ws
      .max_message_size(64 * 1024)        // ★ 상한을 반드시 거세요
      .max_frame_size(64 * 1024)
      .on_upgrade(move |socket| handle_socket(socket, user, room, st))
}

async fn handle_socket(socket: WebSocket, user: AuthUser, room: String, st: AppState) {
    let (mut sender, mut receiver) = socket.split();   // ★ 읽기·쓰기 분리
    let mut rx = st.rooms.subscribe(&room).await;

    // ① 브로드캐스트를 클라이언트로 밀어 넣는 태스크
    let mut send_task = tokio::spawn(async move {
        loop {
            match rx.recv().await {
                Ok(msg) => {
                    let json = serde_json::to_string(&msg).unwrap();
                    if sender.send(Message::Text(json.into())).await.is_err() { break; }
                }
                Err(tokio::sync::broadcast::error::RecvError::Lagged(n)) => {
                    // ★ 놓쳤음을 알리고 계속 — 조용히 넘기면 화면이 어긋납니다
                    let warn = format!(r#"{{"type":"lagged","missed":{n}}}"#);
                    let _ = sender.send(Message::Text(warn.into())).await;
                }
                Err(_) => break,          // 채널이 닫힘
            }
        }
    });

    // ② 클라이언트가 보낸 것을 받아 방에 뿌리는 태스크
    let st2 = st.clone();
    let mut recv_task = tokio::spawn(async move {
        while let Some(Ok(msg)) = receiver.next().await {
            match msg {
                Message::Text(t) => {
                    if t.len() > 4096 { continue; }          // 길이 제한
                    st2.rooms.publish(&room, user.id, t).await;
                }
                Message::Close(_) => break,
                Message::Ping(_) | Message::Pong(_) => {}    // axum 이 자동 응답
                _ => {}
            }
        }
    });

    // ③ 한쪽이 끝나면 다른 쪽도 정리 ★ 이걸 빼면 태스크가 샙니다
    tokio::select! {
        _ = &mut send_task => recv_task.abort(),
        _ = &mut recv_task => send_task.abort(),
    }
    st.rooms.leave(&room, user.id).await;
}

use std::{collections::HashMap, sync::Arc};
use tokio::sync::{broadcast, RwLock};

#[derive(Clone, Serialize)]
pub struct ChatMsg {
    pub seq: u64, pub room: String,
    pub user_id: Uuid, pub text: String,
    pub at: chrono::DateTime<chrono::Utc>,
}

pub struct Room {
    tx: broadcast::Sender<ChatMsg>,
    members: std::sync::atomic::AtomicUsize,
}

#[derive(Clone, Default)]
pub struct Rooms(Arc<RwLock<HashMap<String, Arc<Room>>>>);

impl Rooms {
    pub async fn subscribe(&self, name: &str) -> broadcast::Receiver<ChatMsg> {
        // 있으면 재사용, 없으면 생성 — 읽기 락을 먼저 시도합니다 ★
        if let Some(r) = self.0.read().await.get(name) {
            r.members.fetch_add(1, Ordering::Relaxed);
            return r.tx.subscribe();
        }
        let mut w = self.0.write().await;
        let room = w.entry(name.to_owned()).or_insert_with(|| {
            let (tx, _) = broadcast::channel(256);   // 방당 버퍼 256
            Arc::new(Room { tx, members: AtomicUsize::new(0) })
        });
        room.members.fetch_add(1, Ordering::Relaxed);
        room.tx.subscribe()
    }

    pub async fn publish(&self, name: &str, user: Uuid, text: Utf8Bytes) {
        if let Some(r) = self.0.read().await.get(name) {
            // 구독자가 0명이면 send 가 Err 를 돌려줍니다 — 무시해도 됩니다
            let _ = r.tx.send(ChatMsg { /* ... */ });
        }
    }

    pub async fn leave(&self, name: &str, _user: Uuid) {
        let mut w = self.0.write().await;
        if let Some(r) = w.get(name) {
            if r.members.fetch_sub(1, Ordering::Relaxed) == 1 {
                w.remove(name);      // ★ 빈 방을 지웁니다 (안 지우면 누수)
            }
        }
    }
}

        -> Result<Response<pb::ResolveRes>, Status>
    {

        let token = req.metadata().get("authorization")
            .and_then(|v| v.to_str().ok())
            .ok_or_else(|| Status::unauthenticated("토큰이 없습니다"))?;
        self.st.jwt.verify(token.trim_start_matches("Bearer "))
            .map_err(|_| Status::unauthenticated("토큰이 유효하지 않습니다"))?;

        let slug = req.into_inner().slug;
        match repo::resolve(&self.st.db, &slug).await {
            Ok(Some(url)) => Ok(Response::new(pb::ResolveRes { target_url: url, found: true })),
            Ok(None)      => Err(Status::not_found("없는 슬러그입니다")),
            Err(e)        => { tracing::error!(?e); Err(Status::internal("서버 오류")) }
        }
    }

    type WatchClicksStream = std::pin::Pin<Box<dyn tokio_stream::Stream<
        Item = Result<pb::ClickEvent, Status>> + Send>>;

        -> Result<Response<Self::WatchClicksStream>, Status>
    {
        let rx = self.st.clicks.subscribe();
        let stream = tokio_stream::wrappers::BroadcastStream::new(rx)
            .filter_map(|r| r.ok().map(Ok));
        Ok(Response::new(Box::pin(stream)))

use std::sync::atomic::{AtomicBool, Ordering};

pub static READY: AtomicBool = AtomicBool::new(true);

/// 살아 있는가 — 프로세스가 응답하면 OK. DB 를 보지 않습니다 ★
async fn health() -> StatusCode { StatusCode::OK }

/// 트래픽을 받을 준비가 됐는가 — 의존 대상을 확인합니다
async fn ready(State(st): State<AppState>) -> Response {
    if !READY.load(Ordering::Relaxed) {
        return (StatusCode::SERVICE_UNAVAILABLE, "shutting down").into_response();
    }
    // 타임아웃을 꼭 거세요 — 헬스체크가 매달리면 더 나쁩니다
    let db_ok = tokio::time::timeout(Duration::from_millis(500),
        sqlx::query("SELECT 1").execute(&st.db)).await.is_ok();

    if db_ok { (StatusCode::OK, "ready").into_response() }
    else     { (StatusCode::SERVICE_UNAVAILABLE, "db").into_response() }
}

//   /health 가 DB 를 보면, DB 가 잠깐 느려질 때 쿠버네티스가

pub async fn shutdown_signal() {
    let ctrl_c = async { tokio::signal::ctrl_c().await.ok(); };

    #[cfg(unix)]
    let term = async {
        tokio::signal::unix::signal(tokio::signal::unix::SignalKind::terminate())
            .expect("signal").recv().await;
    };
    #[cfg(not(unix))]
    let term = std::future::pending::<()>();

    tokio::select! { _ = ctrl_c => {}, _ = term => {} }

    tracing::info!("종료 신호를 받았습니다");

    // ① 먼저 /ready 를 실패로 바꿉니다
    READY.store(false, Ordering::Relaxed);

    // ② 로드밸런서가 우리를 목록에서 빼는 데 걸리는 시간만큼 기다립니다 ★
    //    이 대기가 없으면 이미 라우팅된 요청이 502 로 떨어집니다
    tokio::time::sleep(Duration::from_secs(5)).await;
    // 이후 axum::serve 가 새 연결을 안 받고 진행 중인 요청만 마칩니다
}

use axum::{extract::{Path, State, ConnectInfo}, response::Redirect};

pub async fn redirect(
    Path(slug): Path<String>,
    State(st): State<AppState>,
    headers: axum::http::HeaderMap,
) -> Result<Redirect, AppError> {
    // ① 캐시 — 히트하면 DB 를 아예 안 봅니다
    let target: Option<String> = cache::get_target(&st.redis, &slug).await?;

    let target = match target {
        Some(t) if t == cache::NEGATIVE => return Err(AppError::NotFound("링크")),
        Some(t) => t,
        None => {
            // ② 미스 — DB 조회 후 캐시를 채웁니다
            match repo::resolve(&st.db, &slug).await? {
                Some(link) => {
                    let ttl = link.cache_ttl();          // 만료 임박이면 짧게
                    cache::set_target(&st.redis, &slug, &link.target_url, ttl).await?;
                    link.target_url
                }
                None => {
                    // ★ 없는 슬러그도 짧게 캐시합니다 — 캐시 관통 공격 방어
                    cache::set_negative(&st.redis, &slug, Duration::from_secs(60)).await?;
                    return Err(AppError::NotFound("링크"));
                }
            }
        }
    };

    // ③ 통계 — 채널에 던지고 즉시 반환합니다 (응답 지연에 포함되지 않습니다)
    let _ = st.clicks.try_send(ClickEvent {
        slug: slug.clone(),
        at: chrono::Utc::now(),
        country: headers.get("cf-ipcountry")
            .and_then(|v| v.to_str().ok()).map(str::to_owned),
        referer: headers.get(axum::http::header::REFERER)
            .and_then(|v| v.to_str().ok()).map(|s| s.chars().take(200).collect()),
    });   // ★ try_send — 가득 차면 통계를 버립니다. 리다이렉트를 막지 않습니다

    // ④ Redis 카운터도 함께 (실시간 조회용, 원자적)
    let _ = cache::incr_click(&st.redis, &slug).await;

    Ok(Redirect::temporary(&target))     // 302 — 통계를 위해 영구(301)는 피합니다
}

const ALPHABET: &[u8] = b"abcdefghijkmnpqrstuvwxyz23456789";  // 헷갈리는 글자 제외

fn random_slug(len: usize) -> String {
    use rand::Rng;
    let mut rng = rand::thread_rng();
    (0..len).map(|_| ALPHABET[rng.gen_range(0..ALPHABET.len())] as char).collect()
}

#[utoipa::path(post, path = "/api/v1/links", tag = "links",
    request_body = CreateLink,
    responses((status = 201, body = LinkRes), (status = 409, body = ErrBody)),
    security(("bearer" = [])))]
pub async fn create_link(
    user: AuthUser,                       // ← 인증 (w06)
    State(st): State<AppState>,
    Valid(body): Valid<CreateLink>,       // ← 검증 (w02·w07)
) -> ApiResult<Created<LinkRes>> {
    // 사용자 지정 슬러그가 있으면 한 번만, 없으면 충돌 시 재시도
    let mut attempts = 0;
    loop {
        let slug = body.custom_slug.clone()
            .unwrap_or_else(|| random_slug(7));

        match repo::insert_link(&st.db, &slug, &body, user.id).await {
            Ok(link) => {
                let url = format!("{}/{}", st.cfg.app.base_url, link.slug);
                return Ok(Created(url, LinkRes::from(link)));
            }
            // ★ 유니크 위반을 정확히 잡아냅니다 (Postgres SQLSTATE 23505)
            Err(sqlx::Error::Database(e)) if e.code().as_deref() == Some("23505") => {
                if body.custom_slug.is_some() { return Err(AppError::Conflict); }
                attempts += 1;
                if attempts >= 5 { return Err(AppError::Conflict); }
                continue;                 // 랜덤 슬러그면 다시 뽑아 재시도
            }
            Err(e) => return Err(e.into()),
        }
    }
}

use deadpool_redis::{Pool, redis::AsyncCommands};

pub const NEGATIVE: &str = "__none__";       // 없는 링크를 나타내는 표식

fn key(slug: &str) -> String { format!("l:{slug}") }

pub async fn get_target(pool: &Pool, slug: &str) -> Result<Option<String>, AppError> {
    let mut c = pool.get().await.map_err(|e| AppError::Other(e.into()))?;
    // ★ 캐시가 죽어도 서비스는 살아야 합니다 — 에러를 미스로 강등
    Ok(c.get::<_, Option<String>>(key(slug)).await.unwrap_or(None))
}

pub async fn set_target(pool: &Pool, slug: &str, url: &str, ttl: Duration)
    -> Result<(), AppError>
{
    let mut c = pool.get().await.map_err(|e| AppError::Other(e.into()))?;
    // 만료를 살짝 흩뜨립니다 — 동시에 만료돼 DB 로 몰리는 것을 막습니다 ★
    let jitter = fastrand::u64(0..ttl.as_secs() / 5 + 1);
    let _: () = c.set_ex(key(slug), url, ttl.as_secs() + jitter).await
        .unwrap_or(());
    Ok(())
}

// 실시간 카운터 — 원자적으로 증가, 주기적으로 DB 에 반영
pub async fn incr_click(pool: &Pool, slug: &str) -> Result<(), AppError> {
    let mut c = pool.get().await.map_err(|e| AppError::Other(e.into()))?;
    let k = format!("c:{slug}");
    let _: () = redis::pipe().atomic()
        .incr(&k, 1).ignore()
        .expire(&k, 86_400 * 2).ignore()
        .query_async(&mut *c).await.unwrap_or(());
    Ok(())
}

// 링크를 수정·삭제하면 캐시를 반드시 무효화합니다 ★ 빠뜨리기 쉬움
pub async fn invalidate(pool: &Pool, slug: &str) {
    if let Ok(mut c) = pool.get().await {
        let _: Result<(), _> = c.del(key(slug)).await;
    }
}

use tokio::sync::mpsc;

pub fn spawn_click_writer(db: sqlx::PgPool) -> mpsc::Sender<ClickEvent> {
    let (tx, mut rx) = mpsc::channel::<ClickEvent>(10_000);   // 유계 채널 ★

    tokio::spawn(async move {
        let mut buf: Vec<ClickEvent> = Vec::with_capacity(500);
        let mut tick = tokio::time::interval(Duration::from_secs(1));

        loop {
            tokio::select! {
                got = rx.recv() => match got {
                    Some(ev) => {
                        buf.push(ev);
                        if buf.len() >= 500 { flush(&db, &mut buf).await; }
                    }
                    None => { flush(&db, &mut buf).await; break; }  // 종료 시 남은 것 저장
                },
                _ = tick.tick() => { if !buf.is_empty() { flush(&db, &mut buf).await; } }
            }
        }
    });
    tx
}

async fn flush(db: &sqlx::PgPool, buf: &mut Vec<ClickEvent>) {
    if buf.is_empty() { return; }
    // ★ UNNEST 로 한 번에 넣습니다 — 500건이 왕복 1회
    let ids:  Vec<Uuid> = buf.iter().map(|e| e.link_id).collect();
    let ats:  Vec<_>    = buf.iter().map(|e| e.at).collect();
    let ctys: Vec<Option<String>> = buf.iter().map(|e| e.country.clone()).collect();

    let r = sqlx::query!(
        "INSERT INTO clicks (link_id, at, country)
         SELECT * FROM UNNEST($1::uuid[], $2::timestamptz[], $3::text[])",
        &ids, &ats, &ctys as &[Option<String>]
    ).execute(db).await;

    if let Err(e) = r {
        tracing::error!(?e, n = buf.len(), "클릭 배치 저장 실패");
        // ★ 통계는 유실을 허용합니다. 여기서 재시도 루프를 돌면
        //   장애 때 메모리가 터집니다 — 지표로만 남기고 버립니다
        metrics::counter!("clicks_dropped_total").increment(buf.len() as u64);
    }
    buf.clear();
}
